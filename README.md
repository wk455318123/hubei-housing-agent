# 湖北省保租房智能体

“楚小住”是一个面向湖北全省的住房保障智能服务原型。它不是通用聊天框，而是一张可操作的“荆楚安居任务台”：先选申请城市，再完成住房类型分流、项目级资格预判、预算/通勤匹配、房源变化订阅和官方办理连接。

给领导的简要介绍：**拟建设一个省级统一入口，把分散在省、市县、项目和运营平台的住房保障信息按属地接起来。群众先选择实际申请城市，再说明就业、住房、预算和通勤需求；系统区分公租房、保障性租赁住房和人才住房，给出项目级预判、匹配理由、待核验材料和官方办理入口。重点解决跨层级政策难懂、不同城市规则易混、重复咨询多、历史公告误当现房、办理入口难找等问题。**

## 体验方式

推荐使用本地服务运行，避免浏览器直接打开文件时拦截 JSON：

```bash
cd 湖北省保租房智能体
python3 -m http.server 8767
```

浏览器访问：`http://127.0.0.1:8767/`

推荐体验路径：

1. “测资格” → 一键带入武汉示例。
2. “按此结果找房” → 查看同城两张项目卡。
3. 点击“筛选” → 切换宜昌或襄阳，工作地和区域会同步重置。
4. 查看“入口候选 / 历史来源”与匹配依据。
5. “进度” → 开启仅在当前页面模拟的订阅。

## 统一口径

1. **省级政策定方向**：回答保障对象大类、供给方向和责任分工，不能直接判断个人资格。
2. **市县实施规则与项目/批次公告定具体条件**：资格、租金、材料、流程和有效期只适用于载明的城市、项目、批次和人群。
3. **实时房态与仍有效属地入口定“当前可办”**：页面能打开、项目已交付、历史公告写“常态化”或建设已经完成，都不能单独证明当前有房。

公租房、保障性租赁住房和人才住房不得串用规则；武汉规则不得外推到宜昌、襄阳或湖北其他市州。

## 官方办理提示

- 公租房：进入[湖北政务服务网](https://zwfw.hubei.gov.cn/)或“鄂汇办”，选择实际市县后检索“公租房承租资格确认”等当前事项。资格入口不等于当期有实物房源。
- 保障性租赁住房：本轮未核验到一个可直接申请全省所有项目的统一个人入口。应从属地住建部门、城市住房平台或当前项目/运营方公告回源。
- 人才住房：省级人才政策只定方向，人才认定、补贴、项目和申请入口按各市县当前政策执行。武汉、襄阳等已有属地平台，但不能互相替代。

## 样例数据边界

- 武汉安家·空港新城：2025-01-01 项目运营快照。
- 武汉江汉区公租房批次：登记已于 2026-06-29 结束。
- 宜昌秭归屈原东路保租房：公告写常态受理，但仍须再次确认公告未调整、窗口有效和实时房态。
- 宜昌保租房运营服务一期第三批：建设/招标案例，不是招租入口。
- 襄阳市区 2024 年第一批保租房：历史批次，不代表当前有房。
- 襄阳青隽城人才社区：2025-01-01 交付快照，当前人才条件和房态须重查。

原型只输出“可能匹配 / 待进一步核验 / 待补充信息”，不输出“资格通过”。通勤是演示矩阵；订阅不采集手机号、不发送真实消息；系统不代填、代提交、代签约，也不接收身份证号、验证码或银行卡信息。
